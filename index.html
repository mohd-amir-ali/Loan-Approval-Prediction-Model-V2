§3 // CORE ALGORITHM SPECIFICATION & BANKING DOMAIN RELEVANCE

How the CART Decision Tree Algorithm Works & Why It Is Used for Loan Prediction

In your internship notebook (DS_Project.ipynb, Cells 42–46), the predictive core is scikit-learn's CART (Classification and Regression Tree) algorithm instantiated as DecisionTreeClassifier(max_leaf_nodes=25). Unlike black-box neural networks, CART partitions the 9-dimensional borrower feature space into axis-aligned hyper-rectangles using greedy binary recursive splitting.

STEP 1 // GINI IMPURITY CRITERION

Measuring Node Uncertainty

At node t with approval probability p₁ and rejection probability p₀, Gini Impurity measures the likelihood of misclassifying a random borrower:

G(t) = 1 − (p₁² + p₀²)
Root (422 Y, 192 N / 614):
G(N₀) = 1 − (0.6873² + 0.3127²) = 0.4298
STEP 2 // INFORMATION GAIN (ΔGINI)

Selecting the Optimal Feature Split

CART evaluates every feature f and split threshold θ, choosing the split that maximizes weighted Gini reduction:

ΔG = G(t) − [(N_L/N_t)G(t_L) + (N_R/N_t)G(t_R)]
Credit_History ≤ 0.5:
ΔG = 0.4298 − 0.3042 = +0.1256 (Max)
STEP 3 // BEST-FIRST PRUNING

Why max_leaf_nodes=25?

Unpruned trees memorize outlier borrowers (100% train, ~71% test accuracy). Constraining max_leaf_nodes=25 retains only the 24 highest-gain splits:

Train Score (521 loans): 86.56%
Test Score (93 loans): 82.80%
Generalization Gap: Only 3.76%
WHY THE DECISION TREE CLASSIFIER IS UNIQUELY RELEVANT FOR BANKING & CREDIT UNDERWRITING
1. Regulatory Right-to-Explanation: Banking compliance (Basel II/III & Fair Practices Code) mandates giving rejected borrowers concrete reasons (e.g., "Credit History = 0" or "EMI-to-Income > 55%")—which a Decision Tree outputs natively from its path.
2. Non-Linear Feature Conditioning: A $260k loan is risky for a $2,500 single earner, but safe for a $9,600 dual-income household. Hierarchical splits capture conditional risk without manual interaction terms.
3. Skewed Income Robustness: Retail income data has extreme high-earner outliers ($81,000/mo in row 409). Rank-based tree thresholds are completely unaffected by extreme income skewness.
