STEP 3 // ALGORITHM SPECIFICATION & BANKING DOMAIN RELEVANCE

How the CART Decision Tree Algorithm Works & Why It Fits Credit Risk

from sklearn.tree import DecisionTreeClassifier
1. GINI IMPURITY EQUATION G(t)

Measuring Node Uncertainty

At any node t with approval fraction p₁ and rejection fraction p₀, CART computes Gini Impurity to quantify how mixed the classes are:

G(t) = 1 − (p₁² + p₀²)
Root Node (422 Approved, 192 Rejected / 614):
G(Root) = 1 − (0.6873² + 0.3127²) = 0.4298
2. INFORMATION GAIN (ΔGINI)

Greedy Binary Recursive Splitting

CART tests every feature f and threshold θ, choosing the split that maximizes weighted Gini Impurity reduction:

ΔG = G(t) − [ (N_L/N_t)·G(t_L) + (N_R/N_t)·G(t_R) ]
Split on Credit_History ≤ 0.5:
ΔG = 0.4298 − 0.3042 = +0.1256 (Max Gain)
3. LEAF-NODE PRUNING & BANKING FIT

Why max_leaf_nodes=25?

Limiting the tree to 25 leaves prevents overfitting noisy individual loans while preserving a 100% auditable rule path required by banking regulators:

• Training Accuracy (521 loans): 86.56%
• Testing Accuracy (93 loans): 82.80%
• Regulatory Auditability: 100% White-Box
