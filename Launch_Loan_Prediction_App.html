02 // CORE MACHINE LEARNING ALGORITHM SPECIFICATION

Algorithm: Best-First Pruned CART Decision Tree Classifier (DecisionTreeClassifier(max_leaf_nodes=25))

In your internship implementation (DS_Project.ipynb, Cells 42–46), the core predictive model is scikit-learn's CART (Classification and Regression Tree) classifier configured with criterion='gini' and Best-First Leaf-Node Pruning (max_leaf_nodes=25), alongside a depth-constrained variant (max_depth=5, min_samples_leaf=5). Below is the complete mathematical formulation and why this exact algorithm is the gold standard for regulated credit underwriting.

EQUATION 01 // NODE IMPURITY MEASURE

1. Gini Impurity Criterion G(t)

At any node t containing Nt loan applications, let p(c | t) be the fraction of loans belonging to class c ∈ {0 (Rejected), 1 (Approved)}. The Gini Impurity measures the probability that a randomly chosen applicant at node t would be misclassified:

G(t) = 1 − ∑ [ p(c | t) ]² = 1 − (p₁² + p₀²)

Root Node (N₀ = 614 Loans: 422 Approved, 192 Rejected):
p₁ = 422 / 614 = 0.6873  |  p₀ = 192 / 614 = 0.3127
G(Root) = 1 − (0.6873² + 0.3127²) = 1 − (0.4724 + 0.0978) = 0.4298
EQUATION 02 // GREEDY BINARY SPLITTING

2. Gini Impurity Reduction (ΔGini)

For every candidate feature f and threshold θ, CART partitions node t into Left child tL (xf ≤ θ) and Right child tR (xf > θ), selecting the pair (f*, θ*) that maximizes Gini Reduction (Information Gain):

ΔG(t, f, θ) = G(t) − [ (N_L / N_t)·G(t_L) + (N_R / N_t)·G(t_R) ]

Split on Credit_History ≤ 0.5:
• Left (CH=0, N_L=89: 7 Y, 82 N): G(t_L) = 1 − (0.0787² + 0.9213²) = 0.1449
• Right (CH=1, N_R=525: 415 Y, 110 N): G(t_R) = 1 − (0.7905² + 0.2095²) = 0.3312
ΔG = 0.4298 − [ (89/614)(0.1449) + (525/614)(0.3312) ] = +0.1256 (Max Gain)
EQUATION 03 // OVERFITTING CONTROL & DOMAIN RELEVANCE IN RETAIL BANKING

Why max_leaf_nodes=25 Pruning & Why Decision Trees Are Ideal for Loan Underwriting

01 // BEST-FIRST LEAF PRUNING

Preventing Tree Memorization

An unpruned Decision Tree keeps splitting until every leaf has 1 loan (100% train accuracy, but drops to ~71% test accuracy due to noise memorization). By setting max_leaf_nodes=25, scikit-learn uses a Best-First Priority Queue ordered by Nt · ΔG(t), expanding only the 24 most statistically significant credit splits—achieving 86.56% Train and 82.80% Test Accuracy.

02 // BASEL II/III & RBI COMPLIANCE

Mandatory Right-to-Explanation

Under banking regulations (Basel IRB & Equal Credit Opportunity laws), lenders cannot reject a borrower with *"Neural Network Layer 4 output = 0.31"*. A CART Decision Tree generates an explicit boolean audit trail (e.g., Credit_History = 0 OR FOIR > 55%) that loan officers and applicants can verify immediately.

03 // NON-LINEAR INTERACTIONS

Capturing Conditional Risk

In linear models, a large LoanAmount always has the same negative slope. In reality, a $260k loan is high-risk for a single $2,500 earner, but low-risk for a dual-income $9,600 household with clean credit. CART hierarchical splits naturally model these conditional interactions without manual polynomial terms.
